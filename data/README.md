# Data provenance

This repository includes experimentally reported **run-level landing summaries**, limited OpenPTV spatial tracks, and synthetic simulations. They are different evidence types.

See [the source audit](../reports/REAL_DATA_ACQUISITION.md), [the tracked source registry](manifests/source_registry.json), [the reconstructed-particle manifest](manifests/usda_particles_manifest.json), and [the research handoff](../grant/AI_CONTEXT.md).

The 60,370 USDA-derived particle records described elsewhere are **statistically reconstructed from published moments**, not primary individual laboratory observations. The available OpenPTV tracks lack enough experimental timing and release metadata for independent dynamic 3D accuracy evaluation.

Inspect each new source's permission, columns, units, hashes and experiment groups before using it. Do not confuse modeled or imputed inputs with measured quantities.
